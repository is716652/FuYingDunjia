# 时间禁忌与日常行为法则

## 五不过时

**出处**：葛洪曰

**定义**：刚柔日相剋而损其明时，下之干剋今日之干。此时纵有奇门，不可行，百事凶。

### 五不过时对照表

| 日干 | 凶时 | 原理 |
|------|------|------|
| 甲日 | 午时 | 时干剋日干 |
| 乙日 | 己时 | 时干剋日干 |
| 丙日 | 辰时 | 时干剋日干 |
| 丁日 | 卯时 | 时干剋日干 |
| 戊日 | 寅时 | 时干剋日干 |
| 己日 | 丑时 | 时干剋日干 |
| 庚日 | 子时 | 时干剋日干 |
| 辛日 | 酉时 | 时干剋日干 |
| 壬日 | 申时 | 时干剋日干 |
| 癸日 | 未时 | 时干剋日干 |

**影响**：己上为五不过时，损明也，时干剋日干也。

## 饮食左右冠带步履法

**出处**：三元经曰

### 六甲饮食法

**原则**：六甲为饮食，宜旬中六甲。

**示例**：甲子日宜子上也。

### 六丁左右法

**原则**：左右六丁谓左右宜向旬中六丁。

**示例**：甲子旬向卯上。

### 六戊冠带法

**原则**：冠带六戊谓宜旬中六戊。

**示例**：甲子向辰上。

### 步履乾坤法

**操作步骤**：
1. 初举左足而言"乾"
2. 次举右足而言"坤"
3. 又举左足而言"元"
4. 次举右足而言"亨"
5. 又举左足而言"利"
6. 再举右足而言"贞"

**要求**：一步一言行六步而去，勿回顧。

**功效**：隨所去之方，害不能及也。

## 急則從神，緩則從門

**出处**：三元經曰

### 急事法则

**原则**：有急事不擇時，幷三奇吉門。

**行动方位**：
- 天乙所在宮
- 直符之神

### 緩事法则

**原则**：可待三奇吉門而玄。

**行动方位**：
- 天上六戊所在
- 以六戊常為天門

### 应用案例

**冬至上陽一局，甲己之日丙寅時**：
- 天一加六丙於八宮
- 直符在一宮

**急事方位**：
- 东北天乙下
- 正北直符六戊下

**结果**：去皆吉也。
