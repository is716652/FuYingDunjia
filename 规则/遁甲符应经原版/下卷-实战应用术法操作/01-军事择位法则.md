# 军事择位法则

## 五不可击

**出处**：汤谓曰

**核心原则**：五个禁止攻击的位置，我军居之则必雄盛。

1. 第一不击天乙宫
2. 第二不击九天宫
3. 第三不击生门宫
4. 第四不击九地宫
5. 第五不击直使宫

### 应用案例

**阳八局示例**：
- 时间：丙辛之日辛卯时
- 天乙：二宫（西南）阳遁天上直符所在宫，击其冲
- 九天：九宫（正南）
- 生门：三宫（正东）
- 九地：四宫（正西宫东南）
- 直使：八宫（东北）

以上五宫不可击，我军居之必雄胜。

**阴七局示例**：
- 时间：甲己之日丙寅时
- 天乙：七宫（正西）阴遁居地宫，击其冲（正东）
- 天上直符：临九宫（阴遁前一）
- 九天：二宫（西南）
- 生门：一宫（正北）
- 九地：七宫（正西）
- 直使：五宫（寄坤二，西南）

以上五宫不可击，我军居之必雄胜。

## 涉阴危之中

**出处**：经曰

**适用场景**：山河水涧之际，兵不得移转，贼从利方上来。

### 应对策略

#### 阳时作战法
- 令士卒前坦左肩
- 引声大呼
- 鸣鼓击钟
- 先而击之

#### 阴时作战法
- 令士卒啞枚
- 驻军马
- 搥鼓静而待之

### 四面围困破解法

当敌四面围之，当分军为三部：

1. **第一部**：居月建上
2. **第二部**：居月德上（一云日月德上）
3. **第三部**：居生神上
4. **大将位**：居亭上

以此布阵引兵而击之，大胜。
