# 遁甲排盘规则体系

## 原文记载

> 遁甲之法，綱條節目，非直三元，比其通幽洞微，妙與神契，抑又過之。世傳作於風后，黃帝后蓋非古人不能為也。

## 白话讲解

奇门遁甲的排盘方法，其纲领条目不仅仅是三元（上元、中元、下元），比起那些能够洞察幽微、与神明相契合的技艺，还要更加精妙。传说这种方法是由风后所创，黄帝之后，如果不是古代圣贤，是无法创造出这样的方法的。

## 核心排盘要素

### 三层结构
- **上层**：象天，列天蓬等九星
- **中层**：象人，开、休、生、伤、杜、景、死、惊八门  
- **下层**：象地，定八卦、九宫

### 三才定位
天蓬星及休门与坎一宫相对，形成三才（天、地、人）的完整定位。

## 六仪飞布法则

### 阳遁九局
- **顺布六仪**：按顺序布排戊、己、庚、辛、壬、癸
- **逆布三奇**：按相反顺序布排乙、丙、丁

### 阴遁九局
- **逆布六仪**：按相反顺序布排戊、己、庚、辛、壬、癸
- **顺布三奇**：按顺序布排乙、丙、丁

## 直符直使运行法则

### 基本概念
- **直符**：九星为直符，每逐时干转
- **直使**：八门为直使，常随天乙奔
- **直事**：每甲所当之门加本时之支

### 运行规律
```
符者每甲所当之星加本时之干
直事者每甲所当之门加本时之支
直使者即本时所加卦盘之星，谓天乙直使也
```

## 三元九局分法

### 时间分界
- **五日一局**：六十时为一完整周期
- **甲己日为局头**：时头即上中下布局

### 三元划分
```
甲己临仲上元天    临孟之时作中元
临季下元为定局    此名遁甲混三元
```

### 四季对应
- **四仲**：子午卯酉
- **四孟**：寅申己亥  
- **四季**：辰戌丑未

### 局数确定
- 甲己加临子午卯酉为上局
- 加临寅申己亥为中局
- 加临辰戌丑未为下局

## 节气布局长例

### 基本原则
```
一气为一局    气各从    阴阳顺逆起元宫
三三飞去还周局    天地人分上下中
```

### 阳遁布局长例
以冬至为班首，小寒、大寒从焉：
- 一宫起冬至、二宫起小寒、三宫起大寒（上局）
- 四宫起冬至、五宫起小寒、六宫起大寒（下局）  
- 七宫起冬至、八宫起小寒、九宫起大寒（中局）

### 阴遁布局长例
以夏至为班首，小暑、大暑从之：
- 九宫起夏至、八宫起小暑、七宫起大暑（上局）
- 六宫起夏至、五宫起小暑、四宫起大暑（下局）
- 三宫起夏至、二宫起小暑、一宫起大暑（中局）

## 实际操作步骤

### 1. 确定局数
根据用日所属节气和甲己日的天干地支，确定是上元、中元还是下元局。

### 2. 布仪奇
- 看节气分布仪奇
- 六仪随甲转，三奇按规定顺序布排

### 3. 定直符直使
- 以旬头所守宫星为直符
- 寻卦盘甲子戊即是直符位置
- 门盘休门为直事，星盘蓬星为直符

### 4. 加临操作
- 直使加时支：看时支与干在何宫，移门盘所坐直事寻支加之
- 直符加时干：移星盘所坐直符，寻时干加之

## 应用实例

### 阳遁一局实例
假令冬至后用丙寅日，是甲子内五日，上局当用钤中阳遁一局：
- 丙日用艮时为本局，得伤九冲三
- 以直使之门伤加时支九宫
- 直符天冲加时干之三宫
- 视艮之八宫，三盘听得中盘，得开门可以用事
- 星盘得天、上丙奇，下盘得地下丙奇，甚佳

### 吉凶判断标准
- 得休、开、生三门为吉
- 更得三奇临之，可用无疑
- 得门不得奇，亦可用
- 得奇不得门，终非吉
- 奇门俱不得，则凶

## 注意事项

1. **细法推究**：虽大纲如此，但细法推之，奇仪、星门等吉凶各有谓，可否实多端
2. **时宜判断**：虽可用，亦有时乎不可用，亦有时乎可用，殊不可拘执
3. **轻重权衡**：当以轻重、大小而程等用之

这套排盘规则体系是奇门遁甲的核心基础，所有的占断和应用都建立在此基础之上。
