# 透天关法

## 原文记载

> 右透天关法，乃九天玄女深思秘言，搜罗八变，通晓玄微，而首备穷天上之六甲，定人间之五行，削千纸之繁文，归一统之正体。每于一日课，宫三门出入，用之大利。或陈机急用之时，更搜寻于文字，不问空亡，岁煞，是以名为都天大六壬。透天关法，乃主将防身之秘术，凡出将收兵，冒阵解围，无不垂神佑护。或他方人马告来投，牒虚实，皆可断之。凡举事先左脚横，右脚直，后移右脚，横左脚直，七步罡后，向此吉神出。

## 白话讲解

这套透天关法，是九天玄女深入思考的秘传话语，涵盖了八卦的变化，通晓深奥的天道玄理。它首先完备地掌握了天上的六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅），用来确定人间的五行关系，删减了千篇繁杂的文字，归于统一的正宗体系。在每日的占课中，通过确定宫位和三吉门（休、生、景）的出入路径，使用此法非常有利。在紧急应对的时候，还可以通过查阅相关文字资料，不必顾虑空亡、岁煞等因素，因此被称为都天大六壬。透天关法是主将用于防身的秘术，凡是出征、收兵、冲锋陷阵、突围解围，都能得到神灵的保佑护持。如果有其他方的人马前来投降或报告情况，也可以通过此法判断其虚实真假。具体操作时，要先左脚横跨，右脚直立，然后移动右脚，横跨左脚并直立，走完七步罡步后，朝向吉利的神煞方位出发。

```
七步罡后，向此吉神出。
```

### 详细分解
1. **起势**：先左脚横跨
2. **第一步**：右脚直立
3. **第二步**：移动右脚
4. **第三步**：横跨左脚
5. **第四步**：左脚直立
6. **完成**：走完七步罡
7. **行动**：向吉神方位出发
