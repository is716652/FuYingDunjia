# 三奇吉凶判定规则

## 原文记载

> 三奇相會一方吉，不會則凶。三奇入墓最凶，六儀尅戰凶，六儀刑尅凶。

## 白话讲解

三奇（乙、丙、丁）如果能够在同一个方位相聚就是吉利的，如果不相聚则是凶险的。三奇落入墓库是最凶险的情况，六仪之间相互克制争战也是凶险的，六仪之间刑克也是不吉利的。

## 三奇基本概念

### 三奇定义
- **乙奇**：属木，代表日精
- **丙奇**：属火，代表月精  
- **丁奇**：属火，代表星精

### 三奇属性
```
丙奇天月    乙奇地日    丁奇人星
```

## 吉凶判定标准

### 1. 相会为吉
**核心原则**：三奇在同一方位相聚为大吉

**判断方法**：
- 查看排盘中乙、丙、丁三奇是否在同一宫位
- 若三奇同宫，则事情吉利，容易成功
- 若三奇分散，则力量减弱，效果不佳

### 2. 不会为凶
**表现形式**：
- 三奇分散在不同宫位
- 三奇被其他星门冲克
- 三奇落于空亡之地

### 3. 入墓最凶
**墓库概念**：
- 乙奇墓库：乾六宫
- 丙奇墓库：戌乾六宫  
- 丁奇墓库：丑艮八宫

**凶险程度**：三奇入墓是最严重的凶象，主事情难成，多有阻碍。

### 4. 六仪克制
**六仪组成**：戊、己、庚、辛、壬、癸

**克制关系**：
- 六仪相互克制为凶
- 六仪刑克三奇为凶
- 主争斗、冲突、不和

## 出行应用法则

### 呼神字法
> 欲出行者，皆向其方，呼神字，行六十步，左轉於太陰中，太陰別有利例。所呼者，乃所出門下天上之星也。

### 神名字号
```
蓬字子禽    芮字子成    冲字子翹
辅字子卿    禽字子公    心字子襄  
柱字子衢    任字子申    英字子威
```

### 实际操作步骤
1. **选定方向**：根据排盘结果选择吉利方位
2. **呼神名字**：面向该方向，呼喊对应星神的名字
3. **行走六十步**：按指定步数前行
4. **转入太阴**：左转进入太阴方位
5. **寻找太阴**：在太阴区域内活动

### 应用实例
假令冬至上元阳局甲己之日平旦寅时：
- 六甲在八宫，天上六甲天蓬直符加八宫
- 欲出东北方，即呼其神名"子禽"
- 行六十步入太阴下，临四宫
- 天上六丁临九宫，在正南，左回入东南，皆太阴中

## 综合判断要点

### 吉象特征
- 三奇相会一方
- 三奇得门相助
- 三奇临吉星吉门
- 三奇旺相得时

### 凶象特征  
- 三奇分散不聚
- 三奇入墓受困
- 三奇被克被刑
- 三奇落空亡地

### 中和状态
- 三奇虽不相聚但无明显凶象
- 需结合其他因素综合判断
- 可以通过补救措施改善

## 实战应用建议

### 1. 时机选择
- 优先选择三奇相会的时辰
- 避免三奇入墓的时日
- 注意六仪之间的关系

### 2. 方位把握
- 根据三奇所在宫位确定吉利方向
- 结合九星休旺状态选择
- 考虑八门开阖情况

### 3. 补救措施
- 三奇分散时可通过祈祷等方式凝聚
- 三奇受克时可选择其他时机
- 入墓时可寻找化解之法

这套三奇吉凶判定规则是奇门遁甲中判断事情成败的重要依据，对于择日、出行、决策等都有重要的指导意义。
