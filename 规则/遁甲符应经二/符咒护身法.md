# 符咒护身法

## 原文记载

### 基础咒语
> 咒曰：
> 四纵五横，六甲六丁。
> 禹王治道，蚩尤避兵。
> 优游天下，四海往还。
> 所有蛇虎盗贼，一切凶恶，并伏魁罡。
> 之下，不得动作，急急如律令。

### 神煞转化咒
> 又咒曰：
> 逢天狗化为天道，逢太白化为福星，逢白虎化为驿马，逢螣蛇化为喜信，逢太乙化为来福，逢亡神化为阴符，逢劫煞化为便风吹破，敌人营寨逢旄头化为奎璧，奎璧文星，急急如律令。

### 闭六戊法
> 闭六戊法：
> 经曰：欲安营止宿，避病去害，当用真人闭六戊法。为术先置其北，在旬中六戊上，凡野宿安营为之，凶恶不敢犯。甲子旬戊辰，甲戌旬戊寅，甲申旬戊子，甲午旬戊戌，甲辰旬戊申，甲寅旬戊午。

## 白话详细讲解

### 基础护身咒语

#### 咒语含义解析
- **四纵五横**：指符图的结构，象征天地经纬，布下天罗地网封锁凶煞
- **六甲六丁**：六甲（甲子、甲戌、甲申、甲午、甲辰、甲寅）与六丁（丁卯、丁巳、丁未、丁酉、丁亥、丁丑）是道教与奇门遁甲中的"值日神将"，召唤他们护法增强法力

#### 历史典故
- **禹王治道**：大禹治水，象征秩序与安定，寓意此法可平定混乱
- **蚩尤避兵**：蚩尤是上古战神，此处指"让战神退避"，寓意此法可化解兵灾、战争、冲突

#### 功效范围
- **优游天下**：出行顺利，无拘无束
- **四海往还**：可自由往来于四方，不受阻碍
- **降伏凶恶**：所有蛇虎盗贼等凶恶之物都臣服于魁罡神力之下
- **强制执行**："急急如律令"强调咒语的强制力与即时性

### 神煞转化咒语

#### 转化原理
将各种凶神煞气转化为吉庆福气，体现了奇门遁甲"化煞为权"的高级应用。

#### 具体转化对应
- **天狗 → 天道**：凶转吉，得正道
- **太白 → 福星**：金星主杀，化为福气
- **白虎 → 驿马**：凶神变通达
- **螣蛇 → 喜信**：怪异变喜讯
- **太乙 → 来福**：主病灾变福气
- **亡神 → 阴符**：主死亡变符咒护佑
- **劫煞 → 便风吹破**：主劫难被风吹散
- **旄头 → 奎璧**：主兵灾变文星，主文运

### 闭六戊安营法

#### 应用场景
专门用于野外安营扎寨、避病去害，是军阵与个人护身的核心法术。

#### 六戊推算表
根据不同的旬干支确定六戊所在方位：
- **甲子旬** → 戊辰
- **甲戌旬** → 戊寅  
- **甲申旬** → 戊子
- **甲午旬** → 戊戌
- **甲辰旬** → 戊申
- **甲寅旬** → 戊午

#### 操作方法
1. **确定方位**：先确定"六戊"所在方位
2. **画地结界**：在"六戊"方位上，用刀从"鬼门"（东北方）开始，向左画地一周
3. **取中央土**：取中央土，象征"中央戊土"，镇压四方
4. **配合仪式**：吸气叩齿，念咒施法

## 配套操作方法

### 符图绘制
- **天罡符**：代表北斗七星的斗柄，象征天道权威与驱邪力量
- **四纵五横符**：象征天地经纬，可镇压四方凶煞

### 步罡配合
1. **画符**：在地面或纸上画出相关符图
2. **念咒**：边画符边念诵咒语，调动神力
3. **步罡**：配合"禹步"或"七星罡"踏着符图行走
4. **施法**：将符咒贴于门上、随身携带或埋于路途
