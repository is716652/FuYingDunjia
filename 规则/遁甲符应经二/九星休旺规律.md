# 九星休旺规律

## 原文记载

> 三元经曰：九星休旺者，谓九星各旺我生月、相於我月、类月、死於生我月、囚於尅我月、休於我尅月。

## 白话讲解

根据三元经的说法：九星的休旺状态是这样划分的——每颗星都在能够生助我的月份最为旺盛，在与我同类的月份处于次旺状态，在能够生助我的月份走向衰弱，在克制我的月份被囚困，在被我克制的月份处于休眠状态。

## 九星五行属性

### 基本对应关系
- **天蓬星**：属水
- **天英星**：属火  
- **天冲星、天辅星**：属木
- **天心星、天柱星**：属金
- **天任星、天禽星**：属土

## 各星休旺详细规律

### 天蓬水星（坎一宫）
```
旺寅卯月    相亥子月    死申酉月
囚辰戌丑未月    休巳午月
```

**白话解释**：
- **旺於寅卯月**：寅卯属木之氣，水生木也，是谓旺於我生之月
- **相於亥子月**：亥子属水，比和同类也
- **死於申酉月**：金生水也
- **囚於辰戌丑未月**：土克水也  
- **休於巳午月**：是水克火也

### 天英火星（离九宫）
```
旺戌丑未月    相巳午月    死寅卯月
囚亥子月    休申酉月
```

### 天冲星、天辅星（木星）
```
旺巳午月    相寅卯月    死亥子月
囚申酉月    休辰戌丑未月
```

### 天心星、天柱星（金星）
```
旺亥子月    相申酉月    死辰戌丑未月
囚巳午月    休寅卯月
```

### 天任星、天禽星（土星）
```
旺申酉月    相辰戌丑未月    死巳午月
囚寅卯月    休亥子月
```

## 五行生克原理

### 生克关系图
```
水生木 → 木生火 → 火生土 → 土生金 → 金生水
水克火 → 火克金 → 金克木 → 木克土 → 土克水
```

### 休旺判断逻辑
1. **旺**：被我生者（我生木，则木旺）
2. **相**：与我同类（同为水，则相）
3. **死**：生我者（金生水，则水死）
4. **囚**：克我者（土克水，则水囚）
5. **休**：我克者（水克火，则火休）

## 实际应用方法

### 查找步骤
1. **确定月份**：首先确定当前是几月
2. **对应地支**：将月份转换为地支（如正月为寅月）
3. **查找对应**：在各星的休旺表中查找该地支对应的状态
4. **综合判断**：结合其他因素进行最终判断

### 应用实例
假令当前为寅月（正月）：
- **天蓬水星**：旺（寅为木，水生木）
- **天英火星**：死（寅为木，木生火）
- **天冲木星**：相（寅为木，同类相）
- **天心金星**：囚（寅为木，金克木）
- **天任土星**：休（寅为木，木克土）

## 重要提醒

### 灵活运用原则
- 休旺只是判断的一个方面，不能单独作为决定因素
- 需要结合具体时辰、格局、其他神煞综合判断
- 同一颗星在不同情况下可能有不同的表现

### 实战注意事项
1. **月令影响**：月令对九星的影响最为明显
2. **时令配合**：时辰也会对休旺状态产生影响
3. **格局制约**：特殊的格局可能会改变休旺的常规判断
4. **因地制宜**：不同的应用场合需要不同的判断标准

这套九星休旺规律是奇门遁甲中判断星曜力量强弱的重要依据，对于准确占断具有重要意义。
